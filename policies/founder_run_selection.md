# Founder Run Selection Policy

## Include or exclude a handle

- Every handle begins Included in the batch input.
- When the founder marks a handle Excluded for the current run, record the outcome as `Excluded`, use action status `OK`, and state `Founder excluded from this run` as the reason.
- Do not read linked profile sources, qualify, score, rank, or draft outreach for a founder-excluded handle.
- An excluded handle remains in the 50-record reconciliation ledger so the batch audit stays complete.
